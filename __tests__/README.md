# Тесты Flashcardy Project

Этот каталог содержит тесты для проекта Flashcardy.

## Структура тестов

```
__tests__/
├── api/           # Тесты API маршрутов
├── components/    # Тесты React компонентов
├── db/           # Тесты базы данных и схемы
├── utils/        # Тесты утилит
└── README.md     # Этот файл
```

## Запуск тестов

```bash
# Запустить все тесты
npm test

# Запустить тесты в режиме наблюдения
npm run test:watch

# Запустить тесты с покрытием кода
npm run test:coverage
```

## Покрытие кода

Тесты настроены на минимальное покрытие кода:

- Ветки: 70%
- Функции: 70%
- Строки: 70%
- Операторы: 70%

## Типы тестов

### API тесты

- Тестируют маршруты Next.js API
- Проверяют аутентификацию и авторизацию
- Тестируют валидацию входных данных
- Проверяют обработку ошибок

### Компонентные тесты

- Тестируют React компоненты с React Testing Library
- Проверяют пользовательские взаимодействия
- Тестируют условный рендеринг
- Проверяют обработку событий

### Тесты базы данных

- Проверяют структуру схемы Drizzle ORM
- Тестируют связи между таблицами
- Проверяют ограничения и индексы

### Тесты утилит

- Тестируют вспомогательные функции
- Проверяют обработку edge cases
- Тестируют интеграцию с внешними библиотеками

## Моки

Тесты используют следующие моки:

- `@clerk/nextjs` - для аутентификации
- `next/navigation` - для роутинга
- `@/db` - для базы данных
- `lucide-react` - для иконок

## Написание новых тестов

1. Создайте файл с суффиксом `.test.ts` или `.test.tsx`
2. Импортируйте необходимые функции из Jest и Testing Library
3. Напишите тесты, следуя паттерну Arrange-Act-Assert
4. Используйте описательные имена для тестов
5. Группируйте связанные тесты с помощью `describe`

## Пример теста

```typescript
import { describe, it, expect } from "@jest/globals";
import { render, screen } from "@testing-library/react";
import { MyComponent } from "@/components/MyComponent";

describe("MyComponent", () => {
  it("should render correctly", () => {
    render(<MyComponent />);
    expect(screen.getByText("Hello World")).toBeInTheDocument();
  });
});
```
